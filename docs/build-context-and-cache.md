# Build context and cache

## Build context

Что означает точка в docker build.
вот это сумка с моими продуктами бери только от туда
Почему build нужно запускать из корня ecommerce-platform.
если запускать с точкой то он будет собирать только все файлы из корня
Почему COPY не видит весь компьютер.
«скопируй из context», а не «скопируй с диска»

## .dockerignore

Какие группы файлов исключены.
.git
.env
.env.*
!.env.example
vendor
node_modules
storage/logs
*.log
.idea
.vscode
.DS_Store
tmp
Почему исключены .git, .env, vendor, node_modules, logs и IDE-файлы.
могут быть секретные ключи они не должны попасть в образ
Почему .env.example остается доступным.
он является примером ты можешь посмотреть как правильно заполнять

## Layer cache

Почему порядок COPY влияет на cache.
сначала  копируем зависимости и а потом уже код так правильно
Почему dependency files копируются раньше application code.
сначала устанавливаются зависимости а потом уже код чтобы кэш не сбрасывался
Что будет, если поставить COPY . . до dependency step.
тогда сначала поднимется зависимости и код медленно а потом уже проверятся зависимости
