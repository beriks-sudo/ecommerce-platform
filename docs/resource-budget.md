Resource budget

Контейнеры расходуют ресурсы host (на macOS — Linux VM Docker Desktop).
Локальный потолок этой машины: ~7.75 GiB памяти, 10 CPU.
Per-service лимиты распределяют этот бюджет и защищают соседей.

| Service | Memory limit | CPU limit | Почему такой budget |
  |---------|--------------|-----------|---------------------|
| app     | 512m         | 1.0       | PHP runtime, Composer, обработка dev-запросов |
| mysql   | 1g           | 1.0       | базе нужна память на cache/буферы и операции с данными |
| redis   | 128m         | 0.5       | лёгкий кэш для local dev, большие значения не храним | 

Цифры — стартовый договор, не идеал. Если сервис регулярно упирается в лимит —
это сигнал к анализу (оптимизировать/увеличить рамку), а не повод удалить лимит.
Бюджет проверяется через runtime: make inspect-limits SERVICE=<name>.
