# Dockerfile environment contract

## What this image contains

Какая базовая image используется.
FROM php:8.5-cli-alpine

Где внутри image лежит приложение.
WORKDIR /var/www/html
COPY composer.json composer.lock ./

Какая команда запускает container.
docker run 

## Instruction map

Что делает FROM.
взять готовый полуфабрикат-кухню (например, кухню, где PHP уже стоит) — не варить с нуля
Что делает WORKDIR.
выбрать рабочий стол: дальше готовим тут
Что делает COPY.
положить продукты со стола (из «сумки» = context) в заготовку
Что делает RUN.
действие готовки (порезать, поставить вариться) → меняет заготовку
Что делает CMD.
что делать, когда блюдо закажут — команда будущего контейнера
Какая разница между build-time и runtime на примере RUN/CMD.
Это про разницу «когда готовим» и «когда подаём»
## Make workflow

Что делает make build.
собирает образ
Что делает make run.
запускает контейнер
Что делает make image-shell.
заходит внутр образа для диаогностики 
Как make check проверяет image без destructive cleanup.
собирает образ и проверяет чтобы from был внутри
