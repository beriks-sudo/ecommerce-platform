Карта объектов Docker

- container — runtime-экземпляр процесса. Stopped можно удалить, но в нём могут
  остаться логи последнего падения.
- image — образ (рецепт, слои). Пересобирается или скачивается заново, но это
  время и трафик, не всегда быстро.
- network — виртуальная сеть между сервисами. Дешёвая, Compose пересоздаёт.
- volume — хранилище данных, живёт дольше контейнера. Тут локальная база,
  загруженные файлы, состояние очереди. Самый рискованный объект.
- build cache — промежуточные слои сборки. Ускоряет build, может занимать много
  места, но обычно НЕ бизнес-данные.

## Главный контраст
build cache обычно пересобирается (теряешь только скорость следующей сборки).
volume может хранить persistent data, которые из кода не восстанавливаются.
Поэтому build cache и volume — разные категории риска.
