Readiness vs Start

- created — контейнер создан, процесс ещё не запущен.
- running — главный процесс запущен, но роль может быть НЕ готова
  (база ещё инициализируется, app ждёт соседа).
- healthy — healthcheck подтвердил, что сервис готов выполнять роль.
- ready — сервис реально может принимать работу.
