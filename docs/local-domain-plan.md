# Local domain plan

Storefront: http://ecommerce.localho.st
Admin: http://admin.ecommerce.localho.st
API: http://api.ecommerce.localho.st
Traefik dashboard, только локально: http://traefik.ecommerce.localho.st

Почему localho.st удобен.
удобно чтобы не вбивать постоянно ip, под любой контейнер один общий айпишник
Что такое 127.0.0.1.
айпи локальной разработки
Что будет выбирать reverse proxy по Host header.
Он выбирает внутренний сервис (router), куда отправить запрос
