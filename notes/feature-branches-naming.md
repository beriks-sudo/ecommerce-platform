feture-branch обозначает для каких тип работы создана ветка и какой тип внутри
Правило следующее прописываем feature/ и далее прописываем фичу через - и используя lowercase
к примеру
Хорошие
feature/add-html-main-page понятно что автор добавил главную страницу html
feature/add-recorder-telemetry добавил рекордер телеметрию
feature/add-test-case-qa добавил тест кейсы
feature/homework-branches-naming добавил дз 
feature/homework-git-commits добавил дз по комитам

Плохие 
feature/fix не понятно что за фиксы
feature/fixBag не понятно
feature/qa не понятно что внутри ветки
feature/berik тут просто имя
feature/serik и тут имя не понятно что внутри

feature branch -> review -> protected main
Прямой push в main не является целью feature branch
