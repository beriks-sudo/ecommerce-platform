Через три месяца ты сам станешь reviewer'ом собственного кода. Будешь
искать, когда добавили проверку email при регистрации, и через
git log --grep "email verification" найдешь commit за пять секунд.
Если в истории был update User.php, ты будешь читать каждый commit,
который касался User.php, и потеряешь полчаса.
Для release process
Когда из истории собирается changelog или release notes, читаемые
сообщения превращаются в готовые пункты для пользователя. Fix empty cart total when discount code is removed — это уже строка в changelog.
fix — это пункт, который придется переписывать вручную, и часто его
просто пропускают, теряя информацию для пользователей.
